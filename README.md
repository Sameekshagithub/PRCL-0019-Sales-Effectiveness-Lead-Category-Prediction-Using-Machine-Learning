# PRCL-0019-Sales-Effectiveness-Lead-Category-Prediction-Using-Machine-Learning
ML pipeline predicting High/Low Potential sales leads (FicZon Inc., 7,422 records) from MySQL data. Covers EDA, null/outlier handling, feature engineering, and 5 classifiers (Logistic Regression, Decision Tree, Random Forest, KNN, Gradient Boosting) with regularization and train/test/CV overfitting diagnostics.
